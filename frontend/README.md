# Fundo loan application frontend

Next.js (App Router) frontend for the loan application form and outcome pages.

## Getting started

```bash
pnpm install
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000). The app expects the API from
`backend/` to be running and reachable at the URL configured in `.env.local`
(`NEXT_PUBLIC_API_BASE_URL`, defaults to `http://localhost:5080`).

## Scripts

- `pnpm dev` — start the development server
- `pnpm lint` — run ESLint
- `pnpm build` — produce a production build
